# Панели релеев: New API, One API и что откуда берётся

Почти все сайты этого класса стоят на **New API** (форк One API) — отсюда единый набор
эндпоинтов и предсказуемые поля. Отличать их полезно: One API проще, у него нет части
флагов и, что важнее, **не требуется заголовок `New-Api-User`**.

Как определить: `GET /api/status` → `data.version`. У New API там строка вида `v0.9.x`
и десятки полей, включая `passkey_*`, `linuxdo_oauth`, `checkin_enabled`. У One API
(aihubmix) полей около десяти, и есть `top_up_link`.

## Публичные эндпоинты (без ключа)

| Эндпоинт | Что даёт |
|---|---|
| `GET /api/status` | вся конфигурация публичной части, см. ниже |
| `GET /api/about` | текст «о сайте», иногда с условиями |
| `GET /api/notice` | уведомление-модалка |
| `GET /v1/models` | каталог моделей; у большинства станций закрыт без ключа |
| `GET /api/pricing` | прайс с множителями групп, если владелец его открыл |
| `GET /api/uptime/status` | если `uptime_kuma_enabled` — живость каналов |

### Поля `/api/status`, которые решают дело

Деньги и единицы:
- `quota_per_unit` — сколько внутренних единиц в одном долларе. Обычно `500000`, но
  бывает `50000` (api.tniay.top). **Все суммы делить на него**, иначе баланс завышен в 10 раз.
- `usd_exchange_rate` — `1` означает, что панель считает прямо в долларах, `7.3` — в юанях.
- `stripe_unit_price`, `top_up_link` — есть ли платный вход вообще.
- `price` — базовая цена группы, если владелец её опубликовал.

Вход (от этого зависит, сможет ли Босс завестись):
- `register_enabled` — регистрация открыта. Отсутствие поля равно `false`.
- `password_register_enabled` / `password_login_enabled` — можно ли по email+пароль,
  а не только через OAuth.
- `email_verification` — нужен живой ящик. У нас их 678 в `main_email`, так что это не барьер.
- `turnstile_check`, `pow_enabled` — капча и proof-of-work, руками проходит Босс.
- `linuxdo_oauth` + `linuxdo_minimum_trust_level` — вход только через форум LinuxDO.
  **trust level 1 уже барьер, 2 — стоп**: нужен аккаунт с историей на чужом форуме.
- `register_invite_code_required`, `registration_code_enabled`, `invitation_code_enabled`,
  `open_registration_invite_enabled` — нужен код. Иногда код лежит в объявлении открытым
  текстом (api.pie-xian.com публикует «сегодняшний» код), иногда его дают в QQ-группе.
- `github_oauth` — у нас 457 GitHub-аккаунтов в `main_github`, но станции ставят
  минимальный возраст аккаунта (小水管 требует полгода).

Щедрость:
- `checkin_enabled` — ежедневный бонус. Иногда чек-ин на сайте, иногда в QQ-группе
  (api.tniay.top) — второе для нас недоступно.
- `games_enabled`, `game_*_enabled` — квота за мини-игры (ai.huaibao.top).
- `announcements` — **читать целиком**. Там условия акций, номиналы бонусов, множители
  групп, коды регистрации и запреты. Формат — список `{content, publishDate, type}`.
- `faq`, `api_info`, `footer_html` — регион обслуживания, альтернативные домены, правила.
  У api.42w.shop именно во FAQ написано, что материковый Китай не обслуживают, а Европу и
  США — да.

Чего в `/api/status` **нет ни у кого**: `quota_for_new_user`, `quota_for_invitee`,
`quota_for_inviter`. Стартовый баланс и ставку за приглашённого публично не узнать —
только войдя в панель. Проверено на тринадцати живых доменах.

## Эндпоинты по access_token

Авторизация: `Authorization: Bearer <access_token>`. Для **New API** обязателен второй
заголовок `New-Api-User: <panel_id>` — без него 401, и с чужим id тоже 401. Для **One API**
(aihubmix) достаточно одного токена.

| Эндпоинт | Что даёт |
|---|---|
| `GET /api/user/self` | id, username, display_name, `quota`, `used_quota`, `request_count`, `group`, `aff_code` |
| `GET /api/user/self/groups` | доступные группы моделей с множителями — **здесь видно группу с множителем 0** |
| `GET /api/token/?p=0&size=100` | список ключей; после создания видна только маска `sk-1Zjz****9360` |
| `POST /api/token/` | создать ключ, `full_key` в ответе приходит единственный раз |
| `GET /api/data/self?start_timestamp=&end_timestamp=` | расход по дням, отсюда считается суточная трата |
| `GET /api/log/self?p=0&page_size=20` | журнал запросов: модель, токены, списание |
| `GET /api/user/check_in` или `POST /api/user/checkin` | ежедневный бонус, если `checkin_enabled` |

Создание ключа (тело проверено на aihubmix и gorouter):

```json
{"name":"claude-code","remain_quota":0,"expired_time":-1,"unlimited_quota":true,
 "model_limits_enabled":false,"model_limits":"","allow_ips":"","group":"default"}
```

Баланс в долларах = `quota / quota_per_unit`. Сверяй `display_name` из панели с `login`
записи перед записью баланса в базу: токены Босс вставляет руками, и опечатка иначе молча
перезапишет чужую строку. Панель копирует токен с хвостовыми пробелами — `strip()`.

## Где искать партнёрку

По опыту aihubmix её может не быть вовсе, поэтому проверяются оба конца.

Панель: `GET /api/user/aff`, `/api/user/invite`, `/api/user/aff_history`. **404 на всех
трёх означает, что партнёрки нет** — это не ошибка запроса. При этом `aff_code` в профиле
может быть заполнен: сам код существует как приглашение, но ставки за него нет.

Документация: `https://docs.<домен>/llms.txt` — индекс всех страниц одним файлом. Искать
иероглифы `邀请` (приглашение), `返利` (кэшбэк), `推广` (продвижение), `联盟` (партнёрская
программа), `分销` (дистрибуция).

Ловушка: страница с названием вроде «构建 AI 共赢生态» («строим экосистему взаимной выгоды»)
у aihubmix оказалась **APP-Code** — скидкой 10% на собственный платный трафик для
интеграторов. Их же текст уточняет: `用户本身没有优惠` — конечный пользователь скидки не
получает. Это не партнёрка.

## Cloudflare и User-Agent

Часть станций пропускает только браузерный UA; с чужим приходит HTML-заглушка вместо JSON.
Константа UA Chrome Босса, её же держит `scripts/gorouter_balance.py`:

```
Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36
```

Признаки, что упёрлись в Cloudflare, а не в панель: `error code: 1033`, `error code: 522`,
HTML с `<title>404 Not Found</title>` от nginx, или пустой ответ при живом домене.
`error code: 1033` — туннель владельца отключён, то есть станция мертва.

Cookies из браузера для этих панелей бесполезны. У aihubmix авторизация на Clerk, где
`__session` — JWT со временем жизни 60 секунд; у New API сессия не даёт доступа к `/api/*`
без access_token.
