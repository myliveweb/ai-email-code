# Домены .eu.cc


`scripts/import_domains.py` сводит текстовые списки Босса (`~/Загрузки/last`) в `main_domain`.

    uv run python scripts/import_domains.py [--src КАТАЛОГ] [--dry] [--no-dns]

**`.eu.cc` — не зона, а домен третьего уровня.** `eu.cc` принадлежит Gname.com Pte. Ltd.
(Сингапур, IANA 1923) и истекает 2027-06-30; имена под ним Gname продаёт по 1.88 $. Весь
портфель висит на том, что Gname продлит один свой домен, — это не наше владение TLD.

**Владение решает делегирование, а не подпись в файле.** Колонка `status` в `domains.csv`
врёт: у 24 записей из 137 `OWNED` зоны нет вовсе (`sale-ai.eu.cc` — первая же строка).
Файлы, чьё имя начинается с `ok`, — расписки о прошедшей регистрации, и они сошлись
с DNS полностью: 477 из 477 делегированы. Поэтому статус считается пробой
`dig NS` через три резолвера подряд (8.8.8.8 с этой машины отваливается по таймауту,
порядок `1.1.1.1 → 9.9.9.9 → 8.8.8.8`), а не чтением csv.

Статусы: `owned` (расписка `ok-*` либо `OWNED` с делегированием), `unknown` — стоят NS
регистратора `a.share-dns.com`/`b.share-dns.net`, но расписки нет: **это пара по умолчанию
у Gname, и домен другого его клиента выглядел бы точно так же**, поэтому владение тут
выдумывать нельзя; `foreign` — чужие NS (Cloudflare, julydns, rayname); `free` — зона молчит;
`lapsed` — расписка есть, а делегирования нет. На 27.08: 590 / 37 / 36 / 1119 / 0.

Пометки Босса после `---` разбираются тем же правилом, что в импорте аккаунтов: цена в хвосте
(`sverige.eu.cc --- Test sale Market GName $3.00`) значит «уже выставлен», отсюда `for_sale`,
`sale_price` и `marketplace`. Оценки перепродажи (`resale_min`/`resale_max`, полосы
50-500 $) — цифры чат-модели из `domains.csv`, а не рыночные данные; в цену их не ставить.

Результат пробы кэшируется в `log/domains_ns.json` (`--no-dns` берёт оттуда), отчёт —
`log/domains_import.txt`. Кроном не запускается: прогон нужен после новой пачки регистраций.
