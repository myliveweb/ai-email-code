# Импорт списков аккаунтов


Босс ведёт учёт в текстовых файлах от руки, формат плавающий. Разбор — скилл
`.claude/skills/import-site/` (`SKILL.md`, `references/field-patterns.md`,
`references/import-flow.md`). Движок общий, под каждый документ пишется только профиль-JSON
в `scripts/profiles/`; готовые есть на ai.fujcloud.com, apify.com, api.mhoo.cc, gorouter.app,
hotgen.ai, seekai.cc, tabitoken.com, x-llm.net.

Три правила формата: данные в начале строки, личные пометки Босса после `---`; пометка при
этом не мусор, а признак типа значения; и всё, что в хвосте, кроме суммы баланса, едет
в `note` аккаунта — тарифную группу ключа (`codex 0.015x-99%`, `work`) из самих данных
не восстановить. Парсер раскладывает исходник на `_clean.txt`,
`_questions.txt`, `_errors.txt` рядом с ним. **Импорт не запускать, пока `questions` не 0** —
угадывать пароль или ключ нельзя, неверно собранное значение выглядит правдоподобно.
