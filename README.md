# ai-email-code

Учёт аккаунтов на LLM-сайтах и автоматическая выборка кодов подтверждения из почты.

Регистрации идут через ящики на Rambler и Outlook. Сайт присылает письмо с кодом,
а backend достаёт код по правилам, заданным для конкретного сайта: тема письма,
якорь перед кодом, длина и формат (только цифры или цифры с буквами). Якорь здесь
не украшение — без него регулярка цепляет первое попавшееся шестизначное число, а в
письмах это обычно hex-цвет из CSS или id из трекинг-ссылки.

## Стек

- backend — FastAPI, Python 3.13, зависимости через `uv`. Единственный, кто ходит в базу.
- frontend — Next.js 16 (App Router, TypeScript), проксирует `/api/*` на backend.
- база — self-hosted Supabase в Docker.
- чекеры почты — Microsoft Graph для Outlook, IMAP для Rambler.

## Запуск

```bash
uv sync

# backend, порт 4000
uv run uvicorn backend.app.main:app --host 127.0.0.1 --port 4000 --reload

# frontend, порт 4100
cd frontend && npm run dev
```

Конфигурация — в `.env` (в репозиторий не входит): доступ к Supabase, имена моделей
для Ollama, токены почтовых аккаунтов.

## Чего в репозитории нет

`source/`, `data/` и `log/` исключены: там логины, пароли и API-ключи аккаунтов
открытым текстом. Место для них — база, а не git.
